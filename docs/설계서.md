# 링크 정리 봇 설계서 v0.2

> **v0.2 변경 (집 PC 기준)**: 실행 장소를 저가 VPS에서 **집 PC(윈도우)**로 변경. 개발은 지금 PC에서 하고, 나중에 N100급 미니 PC로 폴더째 옮긴다.
> 이유: 비용 0원, 집 IP라 유튜브·인스타 차단이 적음. 음성 변환은 API 대신 로컬 Whisper(faster-whisper)로 변경.

## 1. MVP 범위

### MVP 목표
링크를 보내면 내용을 읽고, 요약해서, 알맞은 폴더에 옵시디언 노트로 저장한다.
연결 제안을 붙이기 전에 **"저장하는 바탕"이 안정적으로 돌아가는지** 확인하는 단계다.

### MVP에 넣는 것
- 텔레그램으로 링크 받기 (내 계정만)
- 유튜브, 인스타(게시물·릴스), 일반 웹 글 수집
- 수집 실패 시 캡처로 대체
- 음성 → 글자, 영상 화면 → 글자 추출
- AI 요약 + 폴더 자동 분류 (기존 폴더 우선)
- 옵시디언 노트 저장 + 깃허브 동기화
- 같은 링크 중복 저장 방지

### MVP에서 뺀 것 (다음 버전)
| 버전 | 기능 |
|---|---|
| v0.2 | 내 목표 파일 + 연결 제안, 공유 시 "○○랑 연결됨" 표시 |
| v0.3 | 실행 키트 (버튼, 교차 검증, 출처 표시) |
| v0.4 | 충돌 정리, 유효기간·보관함, 폴더 합치기 제안 |

### MVP 완료 기준
- 유튜브·인스타·웹 링크를 섞어 10개 연속 보냈을 때 모두 노트가 생긴다
- 폰 옵시디언에서 노트를 확인할 수 있다
- 같은 뜻의 폴더가 두 개 이상 생기지 않는다
- 다른 텔레그램 계정이 말을 걸면 봇이 무시한다

## 2. 전체 구조

```
[폰] 공유 → 텔레그램 봇
        ↓
[집 PC] 봇 프로그램 (파이썬, 상시 실행)
   ① 링크 확인 → ② 수집 → ③ 글자 추출 → ④ AI 요약·분류 → ⑤ 노트 작성
        ↓
[깃허브 비공개 저장소] ← 봇이 올림
        ↓
[폰·PC 옵시디언] ← Git 플러그인이 받아옴
```

## 3. 기술 선택

| 역할 | 선택 | 이유 |
|---|---|---|
| 언어 | 파이썬 | 수집·추출 도구가 전부 파이썬에 있음 |
| 텔레그램 | python-telegram-bot | 가장 많이 쓰임, 자료 많음 |
| 유튜브 수집 | yt-dlp | 제목·설명·자막을 한 번에 |
| 인스타 수집 | instaloader (부계정 로그인) | 캐러셀 이미지와 릴스 모두 처리 |
| 웹 글 수집 | trafilatura | 광고·메뉴 빼고 본문만 뽑아줌 |
| 영상 처리 | ffmpeg | 음성 분리, 화면 캡처 |
| 음성 → 글자 | faster-whisper (PC에서 직접, base 모델로 시작) | 무료. 느리면 모델을 낮추거나 API로 교체 |
| 요약·분류 | **Claude Code (구독)** `claude -p`, 기본 모델 sonnet | 추가 비용 없음. 구독 한도를 같이 쓰므로 한도에 걸리면 나중에 다시 처리 (v0.2 변경: API → 구독) |
| 기록 | SQLite | 처리한 링크 목록, 중복 확인용 |
| 실행 장소 | 집 PC (윈도우). 상시 구동은 N100급 미니 PC 예정 | 무료, 집 IP. 텔레그램은 PC가 먼저 물어보는 방식이라 도메인·포트 설정 불필요 |
| 자바스크립트 실행기 | Deno | 최신 yt-dlp가 유튜브 처리에 필요 (1단계에서 확인) |

## 4. 처리 흐름 상세

### ① 링크 확인
- 보낸 사람이 내 계정인지 확인. 아니면 무시
- 메시지에서 링크 추출 → 이미 저장한 링크면 "이미 저장됨: [폴더/제목]" 답장 후 종료
- "받았어요, 처리 중" 답장

### ② 수집
| 종류 | 가져오는 것 | 실패하면 |
|---|---|---|
| 유튜브 | 제목, 설명, 자막(없으면 음성) | 제목·채널명만 저장하고 "내용 확인 불가" 표시 |
| 인스타 게시물 | 캡션, 이미지 전체 | "캡처 보내주세요" 답장 |
| 인스타 릴스 | 캡션, 영상 | "캡처 보내주세요" 답장 |
| 웹 글 | 제목, 본문 | 링크만 저장 |
| 그 외 | 없음 | 링크만 저장하고 "처리 못 함" 표시 |

**캡처 대체 경로**: 사진(캡처)을 보내면 그냥 저장한다. 링크를 따로 붙일 필요 없다.
- 어느 링크의 캡처인지: 캡션에 링크가 있으면 그 링크 > 30분 안에 수집 실패한 링크 > 링크 없이 저장
- (v0.2 변경: 처음엔 캡션에 링크를 꼭 붙이게 했으나, 번거로워서 자동 연결로 바꿈)
앨범은 사진이 한 장씩 따로 들어오고 캡션은 첫 장에만 붙으므로, 같은 앨범 ID의 사진을 1~2초 모았다가 한 번에 처리한다.

### ③ 글자 추출
- 이미지 → AI가 직접 읽음 (별도 단계 없음)
- 영상 음성 → faster-whisper **small** (PC에서 직접). 캡션·제목을 힌트로 줘서 전문 용어 정확도를 올림
- 영상 화면 → **최대 6장**, 영상 전체에 고르게 (간격은 최소 3초). 3분 이하 짧은 영상만
  - (v0.2 변경: 3초 간격 고정이면 처음 18초만 보게 돼서 고르게 나눔. 긴 영상은 6장으로 의미가 없어 생략)
- 유튜브 자막이 있으면 음성 변환 생략
- 제한: 캐러셀 최대 10장, 자막 없는 영상은 30분 이하만 음성 변환

### ④ AI 요약·분류
AI에게 주는 것: 추출한 글자 + 이미지 + **현재 폴더 목록**

AI가 돌려주는 것 (JSON):
```json
{
  "title": "노트 제목",
  "summary": "3~5줄 요약",
  "key_points": ["핵심 1", "핵심 2"],
  "folder": "기존 폴더명 또는 새 폴더명",
  "is_new_folder": false,
  "tags": ["태그1", "태그2"]
}
```

규칙: 기존 폴더 중 맞는 게 있으면 반드시 재사용. 새 폴더는 기존 어느 것과도 겹치지 않을 때만.

### ⑤ 노트 저장
- 노트 작성 → 깃 커밋 → `pull --rebase` → 푸시 (폰에서 고친 내용과 충돌 방지)
- 답장: "저장 완료: [폴더] 제목"
- 실패 시 1회 재시도, 그래도 실패하면 기록하고 알림

## 5. 옵시디언 폴더 구조

```
vault/
├── 00_내목표.md        ← 내가 관리 (v0.2부터 사용)
├── 내메모/             ← 내가 관리, 봇은 절대 안 건드림
├── 링크/               ← 봇이 관리
│   ├── 원단/
│   │   └── 2026-10-02_린넨 세탁법.md
│   └── 숏폼 편집/
└── 첨부/               ← 봇이 관리, 압축 이미지
```

봇은 `링크/`와 `첨부/`에만 쓴다. 이렇게 나누면 깃 충돌이 생기지 않는다.

### 노트 형식
```markdown
---
url: https://...
source: instagram
saved: 2026-10-02
folder: 원단
tags: [세탁, 린넨]
---
# 린넨 세탁법

## 요약
...

## 핵심
- ...

## 원본 이미지
![[첨부/xxx_1.jpg]]
```

## 6. 보안·비용 관리
- 텔레그램 봇은 내 계정 ID만 허용
- API 키, 인스타 로그인 정보는 PC의 `.env` 파일과 세션 파일에만 두고 깃허브에 올리지 않음
- 인스타는 부계정 사용
- 이미지는 압축해서 저장, 영상 원본은 저장하지 않음
- 링크당 이미지 수 제한 (위 ③ 참고)으로 AI 비용 상한 관리

## 7. 만들기 전 확인
- **수집 테스트**: 봇이 돌 PC에서 인스타·유튜브 링크가 실제로 받아와지는지 (제작법 1단계에서 진행)
- **제안 품질 테스트**: 저장한 링크 20개 내용 + 목표를 Claude에 넣고 연결 제안 받아보기 (MVP 개발과 병행)

## 8. 제작 단계 계획
단계별 만드는 법은 `docs/제작법/`에 있다.
| 단계 | 내용 | 동작 확인 |
|---|---|---|
| 1 | PC 준비 + 수집 도구 단독 테스트 | 인스타·유튜브·웹 링크 각 1개가 서버에서 받아와짐 |
| 2 | 텔레그램 봇 뼈대 + 내 계정 잠금 | 내 메시지에만 답장, 다른 계정 무시 |
| 3 | 수집 모듈 연결 + 캡처 대체 경로 | 링크 보내면 파일이 서버에 저장됨, 실패 시 캡처로 처리됨 |
| 4 | 글자 추출 (음성, 화면) | 릴스 하나에서 음성 글자와 화면 글자가 나옴 |
| 5 | AI 요약·폴더 분류 | JSON 결과가 나오고 기존 폴더를 재사용함 |
| 6 | 옵시디언 저장 + 깃 동기화 | 폰 옵시디언에서 노트가 보임 |
| 7 | 중복 방지, 오류 처리, 상시 실행 | PC 재부팅 후에도 봇이 살아 있음 (작업 스케줄러), 완료 기준 10개 통과 |
