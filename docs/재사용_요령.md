# 재사용 요령 — linkbot에서 배운 것

다른 프로그램을 만들 때 참고할 것만 모았다. 코드는 이 저장소의 파일을 보면 된다.
환경: 윈도우 10, PowerShell 5.1, 파이썬 3.12 가상환경.

---

## 1. 비밀 정보 다루기
- 토큰·키는 `.env`에만 두고 `.gitignore`에 넣는다. 형식만 담은 `.env.example`을 같이 둔다 (값은 비움)
- `.env`의 빈칸은 코드에서 `os.getenv("X") or "기본값"`으로 읽는다. `os.getenv("X", "기본값")`은 빈 문자열을 그대로 돌려줘서, 예를 들어 빈 경로가 현재 폴더가 되어 버린다
- 값을 확인할 때는 출력하지 않는다. "채워짐/비어 있음", "숫자 형식 맞음", "길이 18" 정도만 찍는다
- 잘못 넣는 흔한 실수: 허용할 사용자 ID 칸에 **봇 이름**이나 앱 ID를 넣는 것. 숫자 ID인지 형식 검사를 해 둔다
- 커밋 전에 토큰 모양을 검사한다:
  `git grep --cached -nIE 'sk-ant-|[0-9]{8,10}:[A-Za-z0-9_-]{30,}|[MNO][A-Za-z0-9_-]{23,}\.[A-Za-z0-9_-]{6}\.'`

## 2. 메신저 봇
### 공통
- 봇은 **허용한 계정 ID 하나**에만 반응하게 한다. 무시한 메시지는 답하지 않고 "무시함 (ID 끝 4자리)"만 로그에 남긴다. 그래야 "왜 안 되지?"를 구분할 수 있다
- 처음 실행할 때는 허용 ID를 비워 두고 **설정 모드**로 켠다. 봇이 "당신의 ID: …"라고 답하게 하면 사용자가 ID를 찾을 필요가 없다
- 오래 걸리는 작업은 뒤에서 돌리고(`create_task` + `asyncio.to_thread`), `asyncio.Lock`으로 한 번에 하나씩 처리한다
- 로그는 `print(..., flush=True)`로 프로젝트 안의 `logs/`에 남긴다 (임시 폴더에 두면 찾기 어렵다)
- 받는 쪽 흐름(수집→추출→요약)은 메신저와 상관없는 공통 모듈로 뺀다. 메신저마다 복사하면 고칠 때 둘 다 고쳐야 한다

### 텔레그램 (python-telegram-bot 22)
- 폴링 방식이라 도메인·포트가 필요 없다. 꺼진 동안 온 메시지는 최대 24시간 보관된다
- 수정된 메시지가 오면 `update.message`가 비어서 오류가 난다 → 필터에 `filters.UpdateType.MESSAGE`
- 앨범 사진은 한 장씩 따로 오고 캡션은 첫 장에만 붙는다 → `media_group_id`로 1~2초 모았다가 처리
- 봇이 받을 수 있는 파일은 20MB까지 (프리미엄과 상관없음)
- 같은 토큰으로 봇이 두 개 켜지면 `Conflict` 오류
- **재활용 전화번호 주의**: 이전 주인 계정이 살아 있으면 2단계 인증으로 막힐 수 있다. 새 기기는 24시간 동안 다른 세션을 끊을 수 없다

### 디스코드 (discord.py 2.7)
- 개발자 포털 Bot 탭에서 **MESSAGE CONTENT INTENT**를 켜고 저장해야 메시지 내용을 읽는다. 안 켜면 `PrivilegedIntentsRequired`
- 봇에게 DM을 보내려면 봇이 같은 서버에 있어야 한다 → 나만 있는 서버를 만들고 초대
- 사진 여러 장이 메시지 하나로 와서 앨범 처리가 필요 없다. 메시지는 2000자 제한
- 봇 토큰 확인: `GET https://discord.com/api/v10/users/@me` (헤더 `Authorization: Bot 토큰`)

## 3. 콘텐츠 수집
### 공통
- 공유 추적값(`?stkn=`, `?si=`, `?igsh=`, `utm_`)을 떼고 저장해야 같은 글이 같은 주소가 된다
- 주소 끝 `)` 자르기는 괄호 짝이 안 맞을 때만. 위키 주소 `Obsidian_(software)`가 깨진다
- 서버(VPS) IP는 유튜브·인스타가 봇으로 의심한다. **집 IP**에서 돌리면 대부분 통과한다

### 유튜브 (yt-dlp)
- 최신 yt-dlp는 자바스크립트 실행기가 필요하다: `winget install DenoLand.Deno`, `pip install "yt-dlp[default]"`
- 자막은 수동 자막 우선, 없으면 원어 자동 자막(`-orig`). **번역 자막은 요청하지 않는다** (차단 위험)
- 자막은 `info["subtitles"]`/`info["automatic_captions"]`에서 vtt 주소를 골라 `ydl.urlopen()`으로 받으면 다시 정보 요청을 안 해도 된다
- vtt → 글자: 시간 줄·태그 지우고, 바로 앞 줄과 같은 줄은 뺀다 (자동 자막은 줄이 반복됨)
- 진행률 출력 끄기: `"noprogress": True`

### 인스타 (instaloader 4.15)
- 부계정 세션 파일로 로그인 (`instaloader --login 아이디`, 비밀번호는 직접 입력). 윈도우 세션 위치: `%LOCALAPPDATA%\Instaloader\`
- 갓 만든 계정은 바로 자동 수집에 쓰면 막히기 쉽다. 며칠 사람처럼 쓴다
- `iphone_support=False`: 고화질 API(403 `login_required`)를 끈다. 일반 화질(720p)로도 충분하다
- `max_connection_attempts=1`: 실패해도 반복 요청하지 않는다
- **윈도우에서 저장 경로는 `target`이 아니라 `dirname_pattern`에 넣는다.** `target`에 경로를 넣으면 `\`가 비슷한 다른 글자(`﹨`)로 바뀌어 엉뚱한 폴더가 생긴다
- 직접 받기: `post.get_sidecar_nodes()` → `L.download_pic(경로(확장자 없이), url, post.date_utc)`
- 고화질을 끄면 영상 길이가 0으로 온다 → `ffprobe`로 직접 잰다
- 캐러셀에는 사진과 영상이 섞여 있다. 개수 셀 때 캡션 `.txt`는 뺀다
- **같은 링크를 다시 받기 전에 이미 받았는지 확인한다** (인스타 요청을 아끼는 가장 쉬운 방법)

### 웹 (trafilatura 2.x)
- `fetch_url` → `extract`(본문), `extract_metadata`(제목·사이트명). 200자 미만이면 실패로 본다

## 4. 영상에서 글자 뽑기
### 음성 → 글자 (faster-whisper 1.2)
- **최신 PyAV와 안 맞아서 파일 경로를 주면 오류**(`metadata_errors`)가 난다 → ffmpeg로 소리를 직접 읽어 넘긴다:
  `ffmpeg -i 영상 -vn -ac 1 -ar 16000 -f f32le -` → `np.frombuffer(..., np.float32)`
- `vad_filter=True`: 말 없는 구간(음악)을 건너뛴다
- **캡션·제목을 `initial_prompt`로 주면 전문 용어 정확도가 크게 오른다** ("외북" → "웹훅")
- 단, **언어가 다르면 힌트가 오히려 망친다.** `detect_language()`로 먼저 언어를 보고, 힌트와 같은 언어일 때만 준다
- `no_speech_prob > 0.6`이고 `avg_logprob < -1.0`인 구간은 버린다
- 속도 (134초 영상): i5-10400F에서 base 11초, small 35초. N100은 3~4배 느림
- 모델은 처음 쓸 때 허깅페이스에서 받는다 (small 약 480MB). 다른 PC로 옮기면 다시 받는다

### 화면 캡처 (ffmpeg)
- 3초 간격 고정이면 처음 몇 초만 찍힌다 → 영상 전체에 고르게 N장 (최소 간격만 정한다)
- 긴 영상은 몇 장으로 의미가 없어서 3분 이하만
- `-ss 시간 -i 영상 -frames:v 1 -vf scale=720:-2 -q:v 4`

## 5. Claude를 구독으로 쓰기 (`claude -p`)
- `.env`에 `ANTHROPIC_API_KEY`가 있으면 **구독이 아니라 API로 결제**된다 → 자식 프로세스 환경에서 빼고 실행
- 인증: `claude setup-token`으로 장기 토큰을 받아 `CLAUDE_CODE_OAUTH_TOKEN`에 넣는다 (CLI 로그인은 만료됨)
- 옵션:
  - `--safe-mode`: CLAUDE.md·플러그인·훅 등 개인 설정을 안 읽는다 (한도 절약, 엉뚱한 지시 방지)
  - `--tools ""`: 도구 없이 답만
  - `--json-schema '{...}'`: 형식 강제. 결과는 `structured_output`에 온다
  - `--input-format stream-json --output-format stream-json --verbose`: 메시지에 이미지를 base64로 직접 넣을 수 있다 (파일 읽기 도구가 필요 없음)
  - `--no-session-persistence`, `--strict-mcp-config`, `--system-prompt "..."`
- **윈도우에서는 `claude.cmd`가 JSON 인자의 따옴표를 깨뜨린다** → `node_modules/@anthropic-ai/claude-code/bin/claude.exe`를 직접 실행
- 결과의 `total_cost_usd`는 "API였다면 들었을 금액"이라 구독 사용량 가늠에 쓸 수 있다
- 구독 한도를 같이 쓰므로, 한도에 걸리면 나중에 다시 처리하는 경로를 만든다
- 자동으로 도는 프로그램에 구독을 써도 되는지는 Anthropic 약관을 확인한다

## 6. 윈도우·PowerShell 함정
- `Activate.ps1`이 막히면: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` (사용자가 직접). 아니면 `.\venv\Scripts\python.exe`를 경로째 쓴다
- 한글 출력 깨짐: `$env:PYTHONUTF8 = "1"`
- PowerShell 5.1은 `&&`가 없다 → `;` 또는 `if ($?) { }`
- PowerShell에서 파이썬 한 줄 스크립트(`python -c "..."`)에 따옴표를 넣으면 깨진다 → 파일로 만들어 실행
- bash heredoc으로 파이썬 코드를 쓸 때 `C:\02...`, `\venv`, `\bot` 같은 윈도우 경로는 **이스케이프 문자로 바뀐다** (`\0`, `\v`, `\b`) → 파일 편집 도구로 쓰거나 `chr(92)`로 이어 붙인다
- 창 없이 백그라운드 실행: `Start-Process python.exe -ArgumentList "-u","bot.py" -RedirectStandardOutput logs\bot.log -WindowStyle Hidden`

## 7. 기타
- 실행 장소: 집 PC(무료, 차단 적음) → 상시 구동은 N100 미니 PC. 자세한 건 `docs/미니PC_필요성.md`
- SVG → PNG: ffmpeg 기본 빌드는 SVG를 못 읽는다 → `resvg_py` (`svg_to_bytes(svg_string=..., width=, height=)`), 윈도우 글꼴도 그대로 쓴다
- 메신저 프로필은 원형으로 잘리므로 로고는 가운데 원 안에. 디스코드 배너(680×240)는 왼쪽 아래를 아바타가 덮는다
