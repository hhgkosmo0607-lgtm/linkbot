# 링크 정리 봇 (가칭)

## 한 줄 소개
링크만 보내면 대신 읽고, 주제별로 정리하고, 저장한 것끼리 엮어서 바로 써먹을 수 있게 만들어주는 개인용 봇

## 문제
인스타·유튜브에서 좋은 정보를 저장해도 다시 보지 않는다.
- 다시 볼 계기가 없다
- 쌓이면 뭐가 있는지 모른다
- 영상이나 카드뉴스는 다시 여는 것조차 귀찮다

## 사용 흐름
링크 공유(텔레그램) → 봇이 내용 수집·요약 → 주제별 폴더에 저장 → 기존 저장물과 연결 → 옵시디언에서 확인

## 핵심 기능
- **자동 정리**: 이미지 속 글자, 음성, 화면 자막까지 읽어 요약하고 주제 폴더를 알아서 만든다. 기존 폴더 목록을 먼저 확인해 중복을 막는다.
- **연결 제안**: 내 목표 파일을 기준으로, 서로 다른 저장물을 엮어 생각지 못한 활용법을 제안한다. 제안 페이지는 항상 최신 상태로 유지하고, 링크 공유 시 "○○랑 연결됨" 한 줄만 표시한다.
- **실행 키트**: 원할 때 버튼 하나로 바로 쓸 수 있는 준비물(초안 파일, 체크리스트, 프롬프트)을 만든다. 관련 저장물과 공식 문서를 교차 검증하고, 각 부분의 출처를 표시한다. 같은 주제의 키트가 있으면 새로 만들지 않고 업데이트한다.
- **충돌 정리**: 서로 다른 내용은 판정하지 않고 조건 차이·관점 차이·사실 충돌로 나눠 양쪽 근거를 보여준다.
- **유효기간 관리**: 저장할 때 유효기간 태그를 붙이고, 기간이 지나거나 새 정보로 대체되면 보관함으로 옮긴다. 삭제하지 않고 검색으로는 찾을 수 있다.

## 내 목표 파일
연결 제안과 실행 키트의 기준이 되는 파일
- 큰 방향: 바이브코딩으로 프로그램 제대로 만들기, AI를 활용한 마케팅과 기획
- 지금 하고 있는 프로젝트 (바뀔 때마다 수정)
- 원하는 제안 형태: 바로 써먹을 수 있는 것, 두 목표를 섞은 아이디어

## 구성
| 역할 | 도구 |
|---|---|
| 입력 | 텔레그램 봇 |
| 처리 | 월 몇천 원 상시 서버 |
| 요약·제안 | AI API (이미지 읽기, 음성 변환 포함) |
| 보관·열람 | 옵시디언 + 깃허브 비공개 저장소 동기화 |

## 위험과 대응
- 인스타·유튜브가 서버 접근을 막을 수 있음 → 캡처를 직접 보내는 대체 경로, 필요 시 수집만 집 PC로 이동
- 인스타 자동 수집은 계정 제재 가능성 → 부계정 사용
- 말 없이 화면 글자로만 설명하는 릴스 → 몇 초 간격 화면 캡처 후 글자 읽기
- 제안이 뻔할 수 있음 → 만들기 전 1시간 수동 테스트로 확인
- 동기화 충돌 → 봇이 쓰는 파일과 내 메모 분리
- 봇 무단 사용 → 내 텔레그램 계정 메시지에만 반응

## 만드는 순서
1. 수동 테스트로 제안 품질 확인 + 서버에서 링크 수집 테스트
2. 요약과 옵시디언 저장
3. 인스타 자동 수집
4. 연결 제안
5. 실행 키트, 충돌 정리, 유효기간
