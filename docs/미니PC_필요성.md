# 미니 PC가 필요한 이유

## 한 줄 요약
봇은 **링크를 보낼 때마다 켜져 있어야** 한다. 지금 PC로도 돌아가지만, 24시간 켜 두기엔 전기·소음·관리 부담이 커서 작고 조용하고 전기 적게 먹는 전용 기기를 둔다.

---

## 1. 봇은 "항상 켜져 있는 기기"가 필요하다
- 텔레그램 봇은 PC가 텔레그램에 "새 메시지 있어?"를 계속 물어보는 방식이다. **PC가 꺼져 있으면 아무 일도 안 한다.**
- 꺼져 있는 동안 보낸 링크는 텔레그램이 **최대 24시간** 보관한다. 그 안에 켜면 처리되지만, 그보다 오래 꺼져 있으면 사라진다.
- 실제로 쓰는 순간은 "출근길에 릴스 보다가 공유"처럼 **PC 앞에 없을 때**다. 그때 바로 "저장 완료"가 와야 다시 안 보게 되는 문제를 막을 수 있다.

## 2. 지금 PC를 24시간 켜 두면 생기는 문제
| 문제 | 내용 |
|---|---|
| 전기 요금 | 일반 데스크톱은 놀 때도 40~80W. 24시간이면 한 달 약 30~60kWh. 미니 PC(6~15W)의 5배 이상 |
| 소음·열 | 데스크톱 팬과 그래픽카드 팬이 계속 돈다. 침실·거실에 두기 불편 |
| 작업 방해 | 게임·영상 편집 중에 음성 변환이 돌면 둘 다 느려진다. 재부팅·업데이트 때마다 봇이 꺼진다 |
| 저장 공간 | 지금 PC는 C 드라이브 여유가 **14GB**. 영상·Whisper 모델·노트 첨부가 쌓이면 부족해질 수 있다 |
| 실수 위험 | 평소 쓰는 PC라 폴더 정리하다 `data/`나 `.env`를 지우거나, 끄고 잊어버리기 쉽다 |

## 3. VPS(서버 대여) 대신 미니 PC인 이유
| 항목 | 저가 VPS | 미니 PC (집) |
|---|---|---|
| 비용 | 월 몇천 원, 계속 나감 | 한 번 사면 끝 + 전기세 월 천~이천 원 |
| **유튜브·인스타 차단** | 데이터센터 IP라 **봇으로 의심받기 쉬움** | 집 인터넷 IP라 일반 사용자로 보임 |
| 인스타 계정 | 서버 IP에서 로그인하면 본인 확인·제재가 잦음 | 폰과 같은 집 IP라 자연스러움 |
| 성능 | 1코어 1GB급은 Whisper가 사실상 불가 | N100이면 릴스 1개 2분 안팎 |
| 관리 | 리눅스 명령어 필요 | 윈도우 그대로, 지금 PC와 같은 방식 |

**가장 큰 이유는 차단 문제다.** 1단계 테스트에서 집 PC는 유튜브·인스타가 모두 통과했다. 같은 코드를 서버에서 돌리면 막힐 가능성이 크다.

## 4. 사양이 쓰이는 곳
| 작업 | 부담 | 비고 |
|---|---|---|
| 텔레그램 대기·응답 | 거의 없음 | 메모리 100MB 안팎 |
| 수집 (유튜브·인스타·웹) | 거의 없음 | 인터넷 속도가 좌우 |
| 화면 캡처 (ffmpeg) | 잠깐 | 6장이라 몇 초 |
| **음성 → 글자 (Whisper)** | **큼** | 유일하게 CPU를 오래 씀. small 모델 메모리 약 1~2GB |
| AI 요약 | 없음 | 계산은 Claude 서버에서 |
| 깃 동기화 | 거의 없음 | |

→ CPU는 Whisper 속도만 결정한다. 느려도 실패하지 않고 오래 걸릴 뿐이다.

## 5. 어떤 걸 사면 되나
| 항목 | 기준 | 이유 |
|---|---|---|
| CPU | **Intel N100 / N150** | 전력 6W급, 팬리스 가능, Whisper small이 2분 안팎 |
| 메모리 | 8GB 이상 (16GB면 여유) | Whisper + 윈도우 |
| 저장 | 256GB 이상 | 영상 임시 파일, 노트 첨부 |
| 윈도우 | 11 Pro 권장 | 원격 데스크톱 접속을 받으려면 Pro 필요 (Home이면 다른 원격 도구 사용) |
| 랜 포트 | 유선 권장 | 24시간 연결 안정성 |
| 소음 | 팬리스 or 저소음 후기 확인 | 같은 칩이라도 제품마다 팬 품질이 다름 |

예산 감각 (2026년 검색 기준, 해외 가격 위주라 국내는 따로 확인)
- 팬 있는 N100 8GB/256GB: 약 15~20만 원대 (국내 추정)
- 팬리스 N100 (MINIX Z100-0dB, MeLE Quieter 등): 약 30만 원 안팎

## 6. 지금 PC → 미니 PC 이전 방법 (나중에)
1. 미니 PC에 Python 3.12, ffmpeg, git, Deno 설치
2. `C:\02Workspaces\linkbot` 폴더 통째로 복사 (`venv/`는 빼고 새로 만드는 게 안전)
3. 인스타 세션 파일 `%LOCALAPPDATA%\Instaloader\session-아이디` 복사
4. `pip install` 다시 하고 `python bot.py`로 확인
5. 지금 PC의 봇은 끈다 (두 대가 동시에 켜지면 `Conflict` 오류)
6. 절전 끄기, 자동 업데이트 재부팅 시간 조정, 재부팅 후 자동 실행(7단계) 설정

## 7. 미니 PC가 없어도 되는 경우
- 하루 몇 시간만 켜 둬도 괜찮고, 링크 처리가 늦게 되어도 상관없다
- 지금 PC를 어차피 대부분의 시간 켜 두고 있다

이 경우 지금 PC로 계속 쓰다가, 불편해지면 그때 사도 된다. 코드는 폴더째 옮기면 그대로 돈다.
