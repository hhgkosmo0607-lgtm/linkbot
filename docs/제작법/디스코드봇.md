# 제작법 — 디스코드 봇 (텔레그램 대신 쓰기)

## 이번 단계 목표
텔레그램 봇과 **똑같이 동작하는 디스코드 봇**을 켠다.
폰에서 링크를 디스코드로 공유하면 봇이 수집·글자 추출까지 하고, 캡처도 저장한다.
내 계정이 아닌 사람이 말을 걸면 아무 반응도 하지 않는다.

> 텔레그램 계정이 잠긴 동안 쓰려고 만든다. 코드는 `discord_bot.py` 하나이고,
> 수집·추출은 텔레그램 봇과 같은 `collect.py`, `extract.py`를 그대로 쓴다.
> 봇은 둘 중 하나만 켜도 되고, 토큰이 달라서 **둘 다 같이 켜도 괜찮다.**

---

## 1. 봇 만들기 (PC 브라우저)

1. https://discord.com/developers/applications 접속 → 디스코드 계정으로 로그인
2. 오른쪽 위 **New Application** → 이름 입력 (예: 링크 정리) → 약관 동의 → Create
3. 왼쪽 메뉴 **Bot** 클릭
4. **Reset Token** → 나온 **토큰**을 복사해둔다 (이때 한 번만 보여줌)
5. 같은 화면 아래 **Privileged Gateway Intents**에서 **MESSAGE CONTENT INTENT**를 켠다 → Save Changes
   - 이걸 안 켜면 봇이 메시지 내용(링크)을 못 읽는다
6. 같은 화면의 **Public Bot**은 끈다 (남이 내 봇을 자기 서버에 못 넣게)

> ⚠️ 토큰은 비밀번호와 같다. 깃허브나 채팅(클로드 포함)에 절대 붙여넣지 말 것.
> 실수로 노출됐으면 바로 **Reset Token**으로 새로 발급한다.

---

## 2. 내 서버 만들고 봇 초대

디스코드는 **같은 서버에 있어야** 봇에게 DM을 보낼 수 있다. 나만 있는 서버를 하나 만든다.

1. 디스코드 앱 왼쪽 **+** (서버 추가) → **직접 만들기** → **나와 친구들을 위한 서버** → 이름 입력 (예: 링크봇)
2. 개발자 포털로 돌아가 왼쪽 **OAuth2** → **URL Generator**
3. **SCOPES**에서 `bot` 체크
4. **BOT PERMISSIONS**에서 아래 4개 체크
   - View Channels (Read Messages)
   - Send Messages
   - Attach Files
   - Read Message History
5. 맨 아래 생성된 URL 복사 → 브라우저 주소창에 붙여넣기 → 방금 만든 서버 선택 → 승인

> ✅ 서버 멤버 목록에 봇이 보이면 성공 (아직 꺼져 있어서 오프라인으로 보임)

## 3. 설치와 환경 파일

PowerShell에서 (이미 설치돼 있으면 건너뛰어도 됨):
```powershell
cd C:\02Workspaces\linkbot
.\venv\Scripts\python.exe -m pip install discord.py pillow
```
- `pillow`: 디스코드로 보낸 png·webp 캡처를 jpg로 바꿔 저장할 때 쓴다

`C:\02Workspaces\linkbot\.env` 파일 맨 아래에 **직접** 두 줄을 추가:
```
DISCORD_TOKEN=여기에_토큰
DISCORD_ALLOWED_USER_ID=
```
- `DISCORD_ALLOWED_USER_ID`는 일부러 비워둔다. 4번에서 봇이 알려준다
- 텔레그램 설정(`TELEGRAM_TOKEN`, `ALLOWED_USER_ID`)은 그대로 둔다

## 4. 실행과 확인

### 4-1. 내 ID 알아내기
```powershell
.\venv\Scripts\python.exe discord_bot.py
```
"설정 모드" 문구가 뜨면, 폰 디스코드에서 내 서버 → 멤버 목록 → 봇 누르기 → **메시지 보내기** → 아무 말이나 보낸다.

> ✅ **확인 지점 1**
> 봇이 "당신의 ID: 숫자"로 답하면 통과.

`Ctrl+C`로 끄고, `.env`의 `DISCORD_ALLOWED_USER_ID=` 뒤에 그 숫자를 넣는다.

### 4-2. 링크·캡처 보내기
```powershell
.\venv\Scripts\python.exe discord_bot.py
```
"봇 실행 중"이 뜨면 폰에서 테스트한다.

1. **유튜브 앱 → 공유 → 디스코드 → 봇 DM 선택** (실제로 쓸 방식)
2. **인스타 앱 → 게시물 공유 → 디스코드 → 봇 DM 선택**
3. 캡처 여러 장을 한 번에 봇 DM에 보내기 (갤러리에서 여러 장 선택 → 공유 → 디스코드)
4. 링크 없는 그냥 문장 보내기

> 공유 목록에 봇 DM이 안 보이면, 4-1처럼 봇 DM에 한 번 말을 걸어두면 최근 대화로 뜬다.

> ✅ **확인 지점 2**
> | 보낸 것 | 기대 답장 |
> |---|---|
> | 내 계정으로 첫 메시지 (설정 모드) | 당신의 ID: 숫자 |
> | 유튜브 공유 | 받았어요 [유튜브], 처리 중... → 수집 완료 [유튜브] ... |
> | 인스타 공유 | 받았어요 [인스타], 처리 중... → 수집 완료 또는 "30분 안에 캡처를 보내주시면..." |
> | 캡처 여러 장 | 캡처로 저장했어요: N장 (최대 10장) |
> | 인스타 실패 직후 캡처 | 캡처로 저장했어요 + 실패했던 인스타 링크 |
> | 일반 문장 | 링크를 찾지 못했어요. |

저장 위치는 텔레그램 봇과 같다: `data\collected\` 아래 폴더.

### 4-3. 다른 계정 차단 확인
가족·친구의 디스코드 계정을 내 서버에 초대해서 봇에게 DM이나 채널에 링크를 보내게 한다.

> ✅ **확인 지점 3**
> 봇이 **아무 답도 하지 않고**, PC 터미널에 `무시함: 허용 안 된 계정 (ID 끝 ...1234)`이 찍히면 통과.

## 5. 막혔을 때

| 증상 | 대응 |
|---|---|
| "MESSAGE CONTENT INTENT를 켜고..." 문구 (`PrivilegedIntentsRequired`) | 1번 5단계: 개발자 포털 Bot 화면에서 MESSAGE CONTENT INTENT 켜고 Save |
| "DISCORD_TOKEN이 틀렸어요" (`LoginFailure`) | `.env` 토큰 앞뒤 공백·따옴표 확인. 안 되면 Reset Token으로 새로 받기 |
| 봇에게 DM을 못 보냄 / 메시지 보내기 버튼이 없음 | 봇이 내 서버에 들어와 있는지 확인(2번). 서버 이름 누르기 → 개인정보 보호 설정 → **다이렉트 메시지** 켜기 |
| 봇이 온라인인데 답이 없음 (내 계정인데) | `DISCORD_ALLOWED_USER_ID` 숫자가 맞는지, 봇을 다시 켰는지 확인 |
| 링크를 보냈는데 "링크를 찾지 못했어요" | MESSAGE CONTENT INTENT가 꺼져 있으면 내용이 빈칸으로 온다. 1번 5단계 확인 |
| 공유 목록에 디스코드가 없음 | 공유 화면 "더보기"에서 찾고 디스코드를 고정 |
| 캡처 일부가 "이미지로 읽지 못해서 뺐어요" | 아이폰 HEIC 같은 형식일 수 있음. 스크린샷(png·jpg)으로 다시 보내기 |

**참고**: 지금은 터미널을 닫으면 봇도 꺼진다. 텔레그램 봇과 같이 7단계(작업 스케줄러)에서 자동 실행을 붙인다.
