# 제작법 3단계 — 수집 연결 + 캡처 대체 경로

## 이번 단계 목표
봇에 링크를 보내면 **실제로 내용을 받아서 PC에 저장**한다.
수집에 실패하면 캡처를 받아서 대신 저장한다. 요약·노트는 아직 없다.

## 만든 것
| 파일 | 역할 |
|---|---|
| `collect.py` | 유튜브·인스타·웹 수집, 주소 정리, 저장 |
| `bot.py` | 링크 받으면 `collect.py` 실행, 캡처 앨범 묶어서 저장 |

저장 위치: `data/collected/날짜_종류_ID/`
- `meta.json` — 주소, 제목, 작성자, 설명·캡션·본문, 영상 길이, 파일 목록, 오류
- 유튜브: `subtitle.txt` (자막을 글자만 남긴 것)
- 인스타: `01.jpg`, `02.mp4` … (최대 10개)
- 캡처: `capture-종류_ID/01.jpg` …

## 주요 규칙
- 공유 추적값(`?stkn=`, `?si=`, `utm_` 등)은 떼고 저장 → 같은 글이면 같은 주소
- 수집은 한 번에 하나씩 처리 (인스타 연속 요청 방지)
- 인스타는 실패해도 다시 요청하지 않는다 (`max_connection_attempts=1`), 고화질 API는 끈다
- 유튜브 자막은 수동 자막(한국어→영어) 우선, 없으면 원어 자동 자막. 번역 자막은 쓰지 않는다
- 앨범 사진은 2초 모았다가 한 번에 처리
- 캡처의 원본 링크: 캡션 링크 > 30분 안에 수집 실패한 링크 > 링크 없음

## 실행
```powershell
cd C:\02Workspaces\linkbot
.\venv\Scripts\python.exe bot.py
```

## ✅ 동작 확인
| 보낸 것 | 기대 답장 | 확인할 파일 |
|---|---|---|
| 유튜브 링크 | 수집 완료 [유튜브] 제목, 채널, 길이, 자막 있음/없음 | `subtitle.txt` |
| 인스타 게시물 | 수집 완료 [인스타] 사진 n · 영상 n | `01.jpg` … |
| 인스타 릴스 | 수집 완료 [인스타] 영상 1 | `01.mp4` |
| 웹 기사 | 수집 완료 [웹 글] 제목, 본문 n자 | `meta.json`의 text |
| 캡처 2~3장 (캡션 없이) | 캡처로 저장했어요: n장 (원본 링크 없음) | `capture_…/01.jpg` … |
| 수집 실패 직후 캡처 | 캡처로 저장했어요: n장 + 실패한 링크 | `capture-instagram_…/` |

인스타는 링크당 1번만 보낸다.
