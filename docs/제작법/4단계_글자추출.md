# 제작법 4단계 — 글자 추출 (음성, 화면)

## 이번 단계 목표
영상에서 **말소리를 글자로** 바꾸고, **화면을 캡처**해 둔다.
화면 속 글자는 5단계에서 AI가 캡처 이미지를 직접 읽는다.

## 만든 것
`extract.py` — 수집이 끝나면 봇이 바로 실행한다.

| 결과 | 파일 |
|---|---|
| 음성 → 글자 | `data/collected/…/transcript.txt` |
| 화면 캡처 | `data/collected/…/frames/f01.jpg` … (최대 6장) |
| 생략·실패 사유 | `meta.json`의 `notes` |

## 언제 무엇을 하나
| 경우 | 음성 변환 | 화면 캡처 |
|---|---|---|
| 인스타 영상·릴스 | O | 3분 이하면 O |
| 유튜브, 자막 있음 | X (자막 사용) | 3분 이하면 O |
| 유튜브, 자막 없음, 30분 이하 | O (음성만 받음) | 3분 이하면 O |
| 유튜브, 자막 없음, 30분 초과 | X ("30분 넘어서 생략") | X |
| 소리 없음 / 말소리 없음(음악만) | X (메모에 기록) | 위 규칙대로 |

- 화면 캡처는 영상 전체에 **고르게** 나눠서 찍는다 (최소 3초 간격)
- 음성 변환은 **Whisper small + 캡션 힌트**. 캡션·제목을 힌트로 주면 전문 용어를 잘 알아듣는다
- 느리면 `.env`에 `WHISPER_MODEL=base` 추가 (약 3배 빠름, 정확도는 낮음)

## ✅ 동작 확인
| 보낸 것 | 기대 답장 |
|---|---|
| 인스타 릴스 (말하는 영상) | 수집 완료 → 글자 추출 중... → 글자 추출 완료: 음성 글자 n자 · 화면 캡처 6장 |
| 자막 있는 짧은 유튜브 | 수집 완료 → 글자 추출 완료: 화면 캡처 n장 |
| 자막 없는 유튜브 | 수집 완료 → 글자 추출 중... → 음성 글자 n자 (말이 없으면 "말소리 없음") |

`transcript.txt`를 열어 말한 내용과 비슷한지, `frames/`의 사진이 선명한지 본다.
