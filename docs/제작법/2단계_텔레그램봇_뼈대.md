# 제작법 2단계 — 텔레그램 봇 뼈대 + 내 계정 잠금

## 이번 단계 목표
폰에서 링크를 공유하면 봇이 받아서 **어떤 종류의 링크인지** 답한다.
내 계정이 아닌 사람이 말을 걸면 아무 반응도 하지 않는다.

> 이 단계는 1단계 수집 테스트 결과와 상관없이 진행할 수 있다.
> 다만 3단계(수집 연결)는 1단계 결과표가 나온 뒤에 들어간다.

---

## 1. 봇 만들기 (폰 텔레그램)

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력
3. 봇 표시 이름 입력 (예: 링크 정리)
4. 봇 아이디 입력 — 반드시 `bot`으로 끝나야 함 (예: `gu_linkbot`)
5. 받은 **토큰** (`123456:ABC...` 형태)을 복사해둔다

> ⚠️ 토큰은 비밀번호와 같다. 깃허브나 채팅에 올리지 말 것.

## 3. 봇 코드

`C:\02Workspaces\linkbot\bot.py`:

```python
import os
import re

from dotenv import load_dotenv
from telegram import Update
from telegram.ext import Application, ContextTypes, MessageHandler, filters

load_dotenv()
TOKEN = os.getenv("TELEGRAM_TOKEN")
ALLOWED = os.getenv("ALLOWED_USER_ID", "").strip()

URL_RE = re.compile(r"https?://\S+")


def detect_kind(url: str) -> str:
    if "youtube.com" in url or "youtu.be" in url:
        return "youtube"
    if "instagram.com" in url:
        return "instagram"
    return "web"


KIND_NAME = {"youtube": "유튜브", "instagram": "인스타", "web": "웹 글"}


async def show_my_id(update: Update, context: ContextTypes.DEFAULT_TYPE):
    # 설정 모드: ALLOWED_USER_ID가 비어 있을 때만 동작
    uid = update.effective_user.id
    await update.message.reply_text(
        f"당신의 ID: {uid}\n.env의 ALLOWED_USER_ID에 넣고 봇을 다시 켜세요."
    )


async def handle_message(update: Update, context: ContextTypes.DEFAULT_TYPE):
    text = update.message.text or update.message.caption or ""
    urls = URL_RE.findall(text)
    if not urls:
        await update.message.reply_text("링크를 찾지 못했어요.")
        return
    for url in urls:
        kind = detect_kind(url)
        await update.message.reply_text(f"받았어요 [{KIND_NAME[kind]}]\n{url}")


def main():
    app = Application.builder().token(TOKEN).build()

    if not ALLOWED:
        app.add_handler(MessageHandler(filters.TEXT, show_my_id))
        print("설정 모드: 봇에게 아무 메시지나 보내 ID를 확인하세요.")
    else:
        # 핵심 보안 장치: 허용된 ID에서 온 메시지만 처리, 나머지는 핸들러에 안 걸려서 무시됨
        me = filters.User(user_id=int(ALLOWED))
        app.add_handler(MessageHandler(me & filters.UpdateType.MESSAGE & (filters.TEXT | filters.CAPTION), handle_message))
        print("봇 실행 중 (Ctrl+C로 종료)")

    app.run_polling()


if __name__ == "__main__":
    main()
```

## 4. 실행과 확인

### 4-1. 내 ID 알아내기
```powershell
python bot.py
```
폰 텔레그램에서 내 봇을 찾아 `/start` 또는 아무 말이나 보낸다.

> ✅ **확인 지점 1**
> 봇이 "당신의 ID: 숫자"로 답하면 통과.

`Ctrl+C`로 끄고, `.env`의 `ALLOWED_USER_ID=` 뒤에 그 숫자를 넣는다.

### 4-2. 링크 받기
```powershell
python bot.py
```
"봇 실행 중"이 뜨면 폰에서 테스트한다.

1. 봇 채팅창에 유튜브 링크를 직접 붙여넣기
2. **인스타 앱에서 게시물 → 공유 버튼 → 텔레그램 → 내 봇 선택** (실제로 쓸 방식)
3. 유튜브 앱에서도 같은 방식으로 공유
4. 링크 없는 그냥 문장 보내기

> ✅ **확인 지점 2**
> | 보낸 것 | 기대 답장 |
> |---|---|
> | 유튜브 링크 | 받았어요 [유튜브] |
> | 인스타 앱에서 공유 | 받았어요 [인스타] |
> | 일반 문장 | 링크를 찾지 못했어요 |

### 4-3. 다른 계정 차단 확인
가족·친구 폰이나 다른 텔레그램 계정으로 내 봇에게 링크를 보낸다.

> ✅ **확인 지점 3**
> 봇이 **아무 답도 하지 않으면** 통과. 이게 남이 내 AI 비용을 쓰지 못하게 막는 장치다.

## 5. 막혔을 때

| 증상 | 대응 |
|---|---|
| `InvalidToken` 오류 | `.env` 토큰 앞뒤 공백·따옴표 확인 |
| 봇이 아무 답도 안 함 (내 계정인데) | `ALLOWED_USER_ID` 숫자가 맞는지, 봇을 다시 켰는지 확인 |
| 인스타 공유 목록에 텔레그램이 없음 | 공유 화면 맨 끝 "더보기"에서 찾고, 텔레그램을 즐겨찾기에 고정 |
| `Conflict: terminated by other getUpdates` | 봇이 두 개 켜져 있음. 다른 터미널의 봇을 끄기 |

**참고**: 지금은 터미널을 닫으면 봇도 꺼진다. PC 재부팅 후에도 살아 있게 하는 건 7단계에서 한다(작업 스케줄러).
